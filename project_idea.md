My project will be an assistant to help people
build their own Magic: the Gathering Commander deck.
It's going to take the user through the process of 
building a deck step-by-step through searching for cards
on scryfall.com and returning the results to the user.
The user will be able to append all the cards they want 
to a decklist which they can export and use elsewhere
to buy the cards or playtest the deck. 
The use of this program will be to help new people make
meaningful decisions on building a deck without having 
to know how to use scryfall.com.
